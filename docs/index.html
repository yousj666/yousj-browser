项目简介

Yousj Browser 是一个从零开始编写的浏览器内核项目，目标是打造内存占用低于 Chrome 的轻量级浏览器。项目采用 Python + C + Rust 三语言架构，内核部分以 MIT 协议开源。

核心特性

🔒 安全设计

yousj.security 拦截非 http(s)、私有 IP、回环地址与云元数据，每跳跳转都校验，fail closed。

⚡ 轻量高效

目标内存占用显著低于 Chrome，先做给 AI 用的无头版本。

🛠️ 自研 JS 引擎

内置自研 JavaScript 引擎，V5 版本已公开。

🔧 F12 DevTools

五面板开发者工具，专为 AI 抓取设计。
