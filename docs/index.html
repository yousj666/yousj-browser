为什么是 Yousj Browser？

🔒 安全优先

yousj.security 默认拦截非 http(s)、私有 IP、回环地址与云元数据。每跳跳转独立校验，fail closed。

⚡ 轻量高效

目标内存占用显著低于 Chrome。先做给 AI 用的无头版本，拒绝臃肿。

🛠️ 自研 JS 引擎

内置从零编写的 JavaScript 引擎（js-engine），V5 已公开，不依赖 V8。

🤖 AI 友好

五面板 F12 DevTools 专为 AI 抓取设计，AI 反馈入口一应俱全。

🌐 实用功能

Cookie 持久化、表单自动填写、文件下载、代理支持、历史记录。

📦 开源开放

内核 MIT 协议开源，欢迎提 Issue 和 PR，路线图公开透明。
