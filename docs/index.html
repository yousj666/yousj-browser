Yousj Browser

一个从零编写的浏览器引擎。Python + C + Rust，不依赖 Chromium，为 AI 而生，也为想知道浏览器到底怎么工作的人。

github.com/yousj666/yousj-browser v5.2 Python · C · Rust

01它是什么

不是 Chromium 套壳，不是 Electron 打包。Yousj Browser 的网络、安全、JS 引擎都是自己写的。目标很直接：内存占用比 Chrome 低一大截，先给 AI 当无头浏览器用。

内核
Python + C + Rust 三语言，MIT 开源
JS 引擎
自研 js-engine，V5 已公开，不依赖 V8
安全
yousj.security 默认拦截私有 IP、回环地址、云元数据；每跳跳转独立校验，fail closed
体积
net.get 响应体上限 10MB；DNS pin 防泄漏

02为 AI 做的东西

  • 五面板 DevTools —— 不是给人看的，是给 AI 抓取用的：DOM、网络、存储、控制台，外加一个 AI 反馈入口。
  • 表单填写 / 文件下载 / 代理 / 历史记录 / Cookie 持久化 —— 无头场景该有的都有。
  • 默认搜索引擎 Brave —— 不跟踪的那种。

03上手

git clone https://github.com/yousj666/yousj-browser.git
cd yousj-browser
# 读 README，按你的平台构建

遇到问题直接提 Issue，路线图公开，进度透明。

04人用版

在做了。基于 Supermium（Chromium 分支）换壳，保留 Manifest V2，完整版 uBlock Origin 能装。Windows 一键打包脚本开发中——沙箱里编不出 EXE，得在 Windows 上跑。
